# Sitio del Grupo de Investigación en Ecología Jurídica

Sitio estático en Jekyll publicado con GitHub Pages en
https://lorenzoriano8-png.github.io/grupo-de-investigacion-en-ecologia-juridica/

## Cómo se edita
Desde https://app.pagescms.org (iniciando sesión con la cuenta de GitHub dueña del repositorio). Allí aparecen:

| Sección del panel | Carpeta o archivo |
|---|---|
| Artículos | `_articulos/` |
| Notas de prensa | `_notas/` |
| Lugar de reflexión | `_discusiones/` |
| Miembros | `_integrantes/` |
| Convocatorias (trabaja con nosotros) | `_convocatorias/` |
| Perspectiva, contacto y textos fijos | `_data/sitio.yml` |

Los miembros del grupo se invitan por correo desde el panel y no necesitan cuenta de GitHub. Cada vez que alguien guarda, el sitio se reconstruye solo en uno o dos minutos.

Todo lo que aparece entre corchetes o marcado «[Ejemplo]» es un lugar reservado para reemplazar o borrar.

## Lugar de reflexión
Las intervenciones bajo cada pregunta se guardan en GitHub Discussions (categoría «Lugar de reflexión») mediante giscus. Para intervenir se necesita una cuenta de GitHub.

## Imagen
`assets/rizoma.svg` es un dibujo original generado para el sitio.

## Dominio propio (opcional)
Comprar el dominio, ponerlo en **Settings → Pages → Custom domain**, seguir las indicaciones de DNS de GitHub y dejar `baseurl: ""` en `_config.yml`.
